Hardware Support:
  • CPU: Supported (slow)
  • RTX 3090: 6 hours for 10M steps
  • RTX 4090: 4 hours for 10M steps
  • A100: 2.5 hours for 10M steps
  • H100: 1.5 hours for 10M steps

Training Pipeline:
  1. Load config        → configs/*.yaml
  2. Create environment → src/environment/
  3. Build model        → src/models/
  4. Train with PPO     → src/training/
  5. Save checkpoints   → checkpoints/
  6. Log metrics        → logs/
  7. Evaluate           → evaluate.py
  8. Visualize          → visualize_training.py

Quick Commands:
  • Setup:     ./setup.sh
  • Test:      python test_setup.py
  • Train:     python train.py --config configs/default.yaml
  • Evaluate:  python evaluate.py --checkpoint checkpoints/final_model.pt
  • Monitor:   tensorboard --logdir logs/
  • Visualize: python visualize_training.py --log-dir logs/
