🏗️ ARCHITECTURE:

Vision Pipeline:
  Screenshot → Card Detection → OCR → State Extraction → Model Input
  ↓           ↓                ↓      ↓                  ↓
  MSS (60FPS) Contours        Tesseract  Game State    Observation Dict

Control Pipeline:
  Model Output → Action Decode → Input Commands → Game Execution
  ↓              ↓                ↓                ↓
  Action Dict    Click/Keyboard  PyAutoGUI       Real Game
